# Dash2Frontier

双人实时挖掘竞速网页游戏。两名玩家在各自的浏览器里进入同一个房间，从同一张矿脉的两端出发，连续移动、挖穿方块、用鼠标瞄准技能干扰对手，先进入对方基线上半或下半的**能量门**者获胜。

这是一个 **COMP4021 项目核心原型**：包含完整的联机对局、结算与重开，不包含账号注册、全服排行榜和作弊模式。

## 快速开始

要求 Node.js 20 或以上（开发验证使用 Node 24）。

```bash
npm install
npm start
```

打开 <http://localhost:8000>。

两个人游玩时：

- 同一台电脑：开两个浏览器窗口（或两个标签页）即可，两个标签页各自拥有独立会话。
- 同一局域网：两名玩家都访问服务器启动时打印的 `http://<局域网IP>:8000`，例如 `http://192.168.1.23:8000`。不要让对方访问 `localhost`。
- 进入页面后输入昵称，一名玩家点 **Create Room**，把 **5 位纯数字房间码**（如 `05981`，允许前导 0）发给另一名玩家，对方输入房间码后点 **Join**。两人到齐后自动进入 3 秒倒计时。

修改端口：

```bash
PORT=8080 npm start
```

运行测试：

```bash
npm test
```

## 玩法

- 每局最多 4 分钟。
- 每条基线只有**上半（第 0–6 行）**和**下半（第 21–27 行）**两段是能量门；中间 14 行是封死的基岩。**出生的中间区域不是终点**。
- 玩家中心进入对方最外侧一列、且位于任一能量门行段时立即获胜。
- 时间耗尽仍未破门时，比较双方到最近敌方能量门的平面距离，更近者获胜；完全相同时平局。
- 地图为 72×28，180° 旋转对称。地图会生成纵向断层、横向岩架和基岩团块，迫使双方绕路；每个种子都会验证上下两个门均可到达，并且最短挖掘路线约 2.3–3.5 分钟。
- 深色铆钉方块是**基岩**，无法破坏，必须绕路。

### 连续移动与自动挖掘

- 玩家位置是连续的（格坐标中的浮点坐标），不是逐格跳跃。
- `WASD` / 方向键控制四方向连续移动；窄隧道内有轻微的“车道回正”辅助，避免卡在拐角。
- 玩家面朝且接触到的方块会被自动挖掘，即使松开方向键也会继续完成这一块。
- 转向、选择另一个方块或走开时，当前挖掘目标取消/切换，进度从 0 开始。
- **挖穿方块后玩家不会自动走进那一格**。想前进就继续按住方向键；想停在原地就松开。

### 方块

| 方块 | 挖掘时间 |
| --- | --- |
| Soil（土壤） | 1.0 s |
| Sandstone（砂岩） | 1.8 s |
| Granite（花岗岩） | 2.8 s |
| Obsidian（黑曜石） | 4.0 s |
| Bedrock（基岩） | 不可挖掘 |
| Barricade（技能路障） | 5.0 s |

### 技能

| 键 | 技能 | 消耗 | 冷却 | 瞄准 | 效果 |
| --- | --- | --- | --- | --- | --- |
| `Q` / `1` | Build | 35 能量 | 16 s | 对手附近 | 鼠标点击或拖拽，在对手周围 9 格内放置 1–3 个路障 |
| `E` / `2` | Blast | 50 能量 | 25 s | 自身附近 | 点击 10 格内的一个格子，炸掉以其为中心的 3×3 范围内所有非基岩方块 |
| `R` / `3` | Overdrive | 30 能量 | 18 s | 无需瞄准 | 5 秒内挖掘速度 ×1.8、移动速度 ×1.25 |
| `F` / `4` | Cryo | 30 能量 | 18 s | 对手附近 | 在对手 9 格内指定冰爆点；0.45 秒后半径 2 格内冻结，命中者 4 秒内挖掘 ×0.45、移动 ×0.6 |

- `Q`/`E`/`F` 按下后进入瞄准模式：显示范围圈和预览；左键确认，右键或 `Esc` 取消。Build 可按住左键拖过多格，最多 3 格。再次按同一个技能键也会取消。瞄准时仍可继续移动和挖掘。
- 所有技能的目标、范围、能量、冷却和效果都由服务端重新校验；非法目标不会扣能量。
- 能量初始 50，上限 100，每秒自然恢复 2.5；每破坏一个方块额外获得 2 点能量，Blast 每炸掉一个方块额外获得 1 点。

## 操作

| 操作 | 按键 |
| --- | --- |
| 连续移动 / 自动挖掘 | `W` `A` `S` `D` 或方向键 |
| Build（鼠标范围放置） | `Q` 或 `1` |
| Blast（鼠标 3×3 目标） | `E` 或 `2` |
| Overdrive（立即释放） | `R` 或 `3` |
| Cryo（鼠标延迟冰爆） | `F` 或 `4` |
| 确认瞄准 | 鼠标左键 |
| 取消瞄准 | 鼠标右键或 `Esc` |
| 静音 / 恢复声音 | 游戏画面右上角按钮 |

松开方向键不会中断当前方块的挖掘。页面失焦时客户端会主动清除移动输入，避免角色持续移动。

## 规则与联机细节

- 房间码为 **5 位纯数字**（`00000`–`99999`，允许前导 0）；每个房间最多 2 人。
- 对手断线时，客户端会显示 Rival offline，对局继续进行；刷新页面后会自动用 `sessionStorage` 中的令牌恢复原座位。
- 对局结束后双方都点击 Rematch 会生成新地图再开一局；任意一方离开房间，房间即关闭。
- 服务端不信任客户端：连续移动、碰撞、挖掘目标、技能目标、能量与胜负全部由服务端计算。
- 服务端 tick 为 33 ms（约 30 Hz），每个 tick 广播权威快照；客户端插值渲染，地图变化通过快照内的增量同步。
- 房间数据仅保存在内存中，服务器重启后清空。

## 技术栈与结构

- Node.js + Express 5
- Socket.IO 4（WebSocket，自动回退 polling）
- 原生 HTML / CSS / ES Modules + Canvas 2D
- 无构建步骤、无游戏引擎、无外部图片或音频资源；矿块纹理、角色、粒子和音效分别由 Canvas 与 Web Audio 程序化生成。

### 地图生成

1. 只在左半区生成基础方块、高硬度矿脉、纵向断层、横向岩架和基岩团块。
2. 通过 180° 旋转镜像到右半区（`cell[c][r] = cell[71-c][27-r]`），两名玩家的起始区域和地质机会严格对等。
3. 凿开镜像起始区与四个门的 2 列进近区，并把每条基线中间的非目标行封成基岩。
4. 用 BFS/Dijkstra 对两名玩家的出生点分别验证：**上下两个门都必须可达**，最短时间落在 140–210 秒，并且最短路线相对曼哈顿直线必须产生额外绕路；不满足的种子会重试。极端情况下有保证可通关的十字隧道回退地图。

### 可调参数

平衡性参数集中在 `shared/config.js`：地图尺寸、目标行段、方块挖掘时间、移动速度/碰撞盒、技能消耗/冷却/范围、能量恢复、比赛时长等。修改后重启服务端即可；客户端会从共享模块读取同一份配置。

## 测试

`npm test` 使用 Node 内置 test runner，共 **41** 项：

- **地图**：180° 对称、出生点和四个门洞清空、中间基线封死、双门可达、绕路指标、路径时间区间、同种子复现、非法方块。
- **玩法**：倒计时、连续移动、车道回正、碰撞、自动挖掘、松键续挖、转向切换、挖穿不自动前进、上下门胜利、中段不判胜、超时进度、Build 多格与非法目标、Blast 3×3、Cryo 延迟/命中/落空、Overdrive 移动+挖掘加成、资源/冷却校验、快照增量、断线恢复。
- **联机**：纯数字房间码与前导 0、创建/加入、鼠标技能负载、满房拒绝、断线座位恢复、超时结算后双方重开、离开房间关闭。

另外使用两个独立的 Chromium 浏览器上下文完成了真实流程验证：纯数字房间码创建/加入、连续移动采样、转向切换挖掘、松开按键续挖且不自动前进、Build 拖拽多格、Blast 3×3、Cryo 预警与命中、Overdrive 生效与到期、刷新后自动重连、结算与 Rematch，控制台无报错。一个按最短路径自动驾驶的机器人可在 147–198 秒内走完测试种子，与地图估算一致。

## 当前限制与后续可扩展项

- 房间只存在内存中；服务器重启会丢失正在进行的对局。
- 没有账号注册/登录、全服排行榜、作弊模式和观战。
- 游戏以键鼠操作为主；触屏设备目前没有虚拟方向键。
- 若要继续扩展为完整的 COMP4021 提交版本，可在现有房间/结算流程上增加注册登录、持久化统计与排行榜、作弊模式，并补充首页说明和演示视频。
