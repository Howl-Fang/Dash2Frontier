# Dash2Frontier

双人实时挖掘竞速网页游戏。两名玩家在各自的浏览器里进入同一个房间，从同一张矿脉的两端出发，连续移动、挖穿方块、用鼠标瞄准技能干扰对手，先进入对方基线上半或下半的**能量门**者获胜。

这是一个 **COMP4021 项目核心原型**：包含完整的联机对局、结算与重开，不包含账号注册、全服排行榜和作弊模式。

## 快速开始

要求 Node.js 20 或以上（开发验证使用 Node 24）。

```bash
npm install
npm start
```

打开 <http://localhost:8000>。

两个人游玩时：

- 同一台电脑：开两个浏览器窗口（或两个标签页）即可，两个标签页各自拥有独立会话。
- 同一局域网：两名玩家都访问服务器启动时打印的 `http://<局域网IP>:8000`，例如 `http://192.168.1.23:8000`。不要让对方访问 `localhost`。
- 进入页面后输入昵称，一名玩家点 **Create Room**，把 **5 位纯数字房间码**（如 `05981`，允许前导 0）发给另一名玩家，对方输入房间码后点 **Join**。两人到齐后自动进入 3 秒倒计时。

修改端口：

```bash
PORT=8080 npm start
```

运行测试：

```bash
npm test
```

## 玩法

- 每局最多 4 分钟。
- 每条基线只有**上半（第 0–6 行）**和**下半（第 21–27 行）**两段是能量门；中间 14 行是封死的基岩。**出生的中间区域不是终点**。
- 玩家中心进入对方最外侧一列、且位于任一能量门行段时立即获胜。
- 时间耗尽仍未破门时，比较双方到最近敌方能量门的平面距离，更近者获胜；完全相同时平局。
- 地图为 72×28，180° 旋转对称。地图会生成矿脉、基岩团块（clusters）以及上下两侧的幸运方块。2026-11-24 调整：移除了纵向基岩断层与横向基岩岩架，避免地图被切割得过于破碎导致幸运方块不可达；幸运方块密度提高后基础基岩概率同步上调到 9%。每个种子都会验证上下两个门均可到达，并且最短挖掘路线约 2.3–3.5 分钟。
- 深色铆钉方块是**基岩**，无法破坏，必须绕路。

### 连续移动与自动挖掘

- 玩家位置是连续的（格坐标中的浮点坐标），不是逐格跳跃。
- `WASD` / 方向键控制四方向连续移动；窄隧道内有轻微的“车道回正”辅助，避免卡在拐角。
- 玩家面朝且接触到的方块会被自动挖掘，即使松开方向键也会继续完成这一块。
- 转向、选择另一个方块或走开时，当前挖掘目标取消/切换，进度从 0 开始。
- **挖穿方块后玩家不会自动走进那一格**。想前进就继续按住方向键；想停在原地就松开。

### 方块

| 方块 | 挖掘时间 |
| --- | --- |
| Soil（土壤） | 1.0 s |
| Sandstone（砂岩） | 1.8 s |
| Granite（花岗岩） | 2.8 s |
| Obsidian（黑曜石） | 4.0 s |
| Bedrock（基岩） | 不可挖掘 |
| Barricade（技能路障） | 5.0 s |
| Lucky Block（幸运方块） | 0.3 s |

### 幸运方块

幸运方块只生成在地图的上、下两侧（第 1–6 行与第 21–26 行），并随地图 180° 镜像成对出现，双方机会对等。当前密度为每半区 20 对（全图 40 块）。它挖掘极快（0.3 s），挖掉后按权重抽取一个效果：

| 类别 | 效果 | 默认作用对象 | 说明 |
| --- | --- | --- | --- |
| Buff | **回响形态** | 自己 | 8 秒内每次挖掘额外破坏正前方一个方块 |
| Buff | **以手拒之（Reject）** | 自己 | 12 秒内免疫所有 debuff |
| Buff | **好运** | 自己 | 接下来 2 个幸运方块必定是 buff（四叶草 SVG 图标，不会再次抽到好运） |
| Debuff | **颠倒** | 对手优先 | 6 秒内移动方向与朝向反转 |
| Debuff | **迷雾** | 对手优先 | 8 秒内只能看到自身周围有限视野 |
| Debuff | **吸能** | 对手优先 | 立即清空全部能量 |
| Debuff | **迟滞** | 对手优先 | 10 秒内技能冷却 ×1.8 |
| Debuff | **冻结** | 对手优先 | 原地冻结最多 6 秒，连续按方向键 8 次可提前解冻（QTE） |
| Debuff | **厄运** | 对手优先 | 12 秒内该玩家挖到的幸运方块只会给自己上 debuff |
| Debuff | **封锁** | 全局 | 8 秒内封锁双方目标门：无法进入且不判定胜利 |
| Tradeoff | **接管** | 自己 | 10 秒内不能改变方向，沿原方向持续挖掘，但挖掘 ×3 |
| Tradeoff | **考试** | 自己 | 弹出 3 道 100 以内加减法选择题，限时 10 秒；全对挖掘 ×2（20 秒），否则 ×0.5（20 秒） |
| Tradeoff | **平衡** | 自己 | 20 秒内挖掘时若横向进度落后则 ×3，领先则 ÷3，相同则随机 |
| Tradeoff | **平凡** | 自己 | 15 秒内免疫所有 buff 与 debuff（不免疫 tradeoff） |
| 地形 | **软化** | 地形 | 以幸运方块为中心的 7×7 可挖岩层变为土壤 |
| 地形 | **筑墙** | 地形 | 玩家所在整列（除自身格子）变为黑曜石 |
| 地形 | **硬化** | 地形 | 以幸运方块为中心的 3×3 岩层变为黑曜石 |

- **目标规则**：buff 与 tradeoff 默认作用于挖掘者；debuff 有 80% 作用于对手、20% 作用于自己。持有“好运”时必定抽到 buff；持有“厄运”时必定给自己上 debuff。
- **免疫规则**：“平凡”免疫所有 buff/debuff，“以手拒之”免疫所有 debuff；被免疫时仍会广播 RESISTED 反馈。
- 地形类效果不会改写两条基线列，也不会改变玩家或对手所在的格子，因此永远不会封死能量门或把玩家埋进方块。
- 被 Blast 炸掉的幸运方块不会触发效果，只有真正挖穿它才会抽奖。
- 效果判定、目标选择、免疫与数值施加全部由服务端执行。

### 状态与反馈

- **角色头顶**：发生在某个玩家身上的事件（冰冻、吸能、迟滞、好运、接管、封锁等）以浮动文字显示在该角色头上，多条同时出现时向上堆叠，不会重叠。
- **地图上方**：全局事件（开赛、封锁开启/解除、作弊模式、考试结果）显示在地图上方空白处的通知条中。
- **HUD 状态栏**：双方当前所有激活的 buff / debuff / tradeoff 以「SVG 图标 + 名称 + 剩余时间」显示在玩家卡上；图标是手绘的统一线稿（`public/js/icons.js`），不是文字 emoji；鼠标悬停显示名称与完整描述。
- 右上角 toast 只保留给系统提示（连接、房间、非法操作等）。

### 技能

| 键 | 技能 | 消耗 | 冷却 | 瞄准 | 效果 |
| --- | --- | --- | --- | --- | --- |
| `Q` / `1` | Build | 35 能量 | 16 s | 对手附近 | 鼠标点击或拖拽，在对手周围 9 格内放置 1–3 个路障 |
| `E` / `2` | Blast | 50 能量 | 25 s | 自身附近 | 点击 10 格内的一个格子，炸掉以其为中心的 3×3 范围内所有非基岩方块 |
| `R` / `3` | Overdrive | 30 能量 | 18 s | 无需瞄准 | 5 秒内挖掘速度 ×1.8、移动速度 ×1.25 |
| `F` / `4` | Cryo | 30 能量 | 18 s | 对手附近 | 在对手 9 格内指定冰爆点；0.45 秒后半径 2 格内冻结，命中者 4 秒内挖掘 ×0.45、移动 ×0.6 |

- `Q`/`E`/`F` 按下后进入瞄准模式：显示范围圈和预览；左键确认，右键或 `Esc` 取消。Build 可按住左键拖过多格，最多 3 格。再次按同一个技能键也会取消。瞄准时仍可继续移动和挖掘。
- 所有技能的目标、范围、能量、冷却和效果都由服务端重新校验；非法目标不会扣能量。
- 能量初始 50，上限 100，每秒自然恢复 2.5；每破坏一个方块额外获得 2 点能量，Blast 每炸掉一个方块额外获得 1 点。

### 作弊模式（隐藏）

- 对局中连按三次 `C` 开启，开启后按一次 `C` 即可关闭。
- 开启时同时生效：**秒挖**（每次 tick 直接破坏面朝方块）、**可挖基岩**、以及让对手**原地冻结 6 秒**（完全无法移动或挖掘，与 Cryo 的减速不同）。
- 关闭后立即恢复正常挖掘与基岩不可破坏规则；冻结是一次性的定时效果，不会随作弊模式常驻。
- 作弊状态同样由服务端维护并写入快照，双方都会看到提示、冻结与作弊光环。

### 开发者菜单（隐藏）

- 对局中连按三次 `]` 打开右侧侧边栏，再次三连 `]` 或用关闭按钮 / `Esc` 收起。
- 侧边栏按 Buff / Debuff / Tradeoff 分组列出所有可施加的状态，可先选择作用对象（Self / Rival）再点击 Trigger。
- 用于演示与测试，效果仍由服务端校验并施加；离开对局时自动关闭。

## 规则与联机细节

- 房间码为 **5 位纯数字**（`00000`–`99999`，允许前导 0）；每个房间最多 2 人。
- 对手断线时，客户端会显示 Rival offline，对局继续进行；刷新页面后会自动用 `sessionStorage` 中的令牌恢复原座位。
- 对局结束后双方都点击 Rematch 会生成新地图再开一局；任意一方离开房间，房间即关闭。
- 服务端不信任客户端：连续移动、碰撞、挖掘目标、技能目标、能量与胜负全部由服务端计算。
- 服务端模拟 tick 为 33 ms（约 30 Hz），快照按 20 Hz 限流广播并只携带活跃状态；考试题目只在下发时发送一次。客户端对自己的角色做本地预测，只有与服务端偏差较大时才强制拉回，网络较差时移动不再明显卡顿。
- 房间数据仅保存在内存中，服务器重启后清空。

## 技术栈与结构

- Node.js + Express 5
- Socket.IO 4（WebSocket，自动回退 polling）

### 地图生成

1. 只在左半区生成基础方块、高硬度矿脉和基岩团块。
2. 通过 180° 旋转镜像到右半区（`cell[c][r] = cell[71-c][27-r]`），两名玩家的起始区域和地质机会严格对等。
3. 凿开镜像起始区与四个门的 2 列进近区，并把每条基线中间的非目标行封成基岩。
4. 用 BFS/Dijkstra 对两名玩家的出生点分别验证：**上下两个门都必须可达**，最短时间落在 140–210 秒，并且最短路线相对曼哈顿直线必须产生额外绕路；不满足的种子会重试。极端情况下有保证可通关的十字隧道回退地图。

### 可调参数

平衡性参数集中在 `shared/config.js`：地图尺寸、目标行段、方块挖掘时间、移动速度/碰撞盒、技能消耗/冷却/范围、能量恢复、比赛时长等。修改后重启服务端即可；客户端会从共享模块读取同一份配置。

## 测试

`npm test` 使用 Node 内置 test runner，共 **65** 项：

- **地图**：180° 对称、出生点和四个门洞清空、中间基线封死、双门可达、绕路指标、路径时间区间、同种子复现、非法方块、幸运方块只出现在上下两侧且成对镜像。
- **玩法**：倒计时、连续移动、车道回正、碰撞、自动挖掘、松键续挖、转向切换、挖穿不自动前进、上下门胜利、中段不判胜、超时进度、Build 多格与非法目标、Blast 3×3、Cryo 延迟/命中/落空、Overdrive 移动+挖掘加成、资源/冷却校验、快照增量、断线恢复、地形幸运效果、debuff 目标规则、好运/厄运、免疫、吸能、迟滞、QTE 冻结与解冻、接管、平衡、考试通过/失败/超时、封锁、作弊模式秒挖/破基岩/冻结与关闭恢复。
- **联机**：纯数字房间码与前导 0、创建/加入、鼠标技能负载、满房拒绝、断线座位恢复、超时结算后双方重开、离开房间关闭、作弊模式开关、开发者效果定向施加、QTE 解冻同步。

另外使用两个独立的 Chromium 浏览器上下文完成了真实流程验证：纯数字房间码创建/加入、连续移动采样、转向切换挖掘、松开按键续挖且不自动前进、Build 拖拽多格、Blast 3×3、Cryo 预警与命中、Overdrive 生效与到期、刷新后自动重连、结算与 Rematch，控制台无报错。一个按最短路径自动驾驶的机器人可在 147–198 秒内走完测试种子，与地图估算一致。

## 当前限制与后续可扩展项

- 房间只存在内存中；服务器重启会丢失正在进行的对局。
- 没有账号注册/登录、全服排行榜和观战。
- 游戏以键鼠操作为主；触屏设备目前没有虚拟方向键。
- 若要继续扩展为完整的 COMP4021 提交版本，可在现有房间/结算流程上增加注册登录、持久化统计与排行榜，并补充首页说明和演示视频。
